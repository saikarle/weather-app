# 🌤️ Weather App

A responsive Weather App built using React, JavaScript, and CSS.

## 📌 About the Project

I built this project to improve my React and JavaScript skills.

While developing this project, I learned:

- How to handle APIs in React.
- How to fetch data from an API.
- How to handle API responses.
- How to use basic JavaScript concepts in a real-world project.
- How to manage and display dynamic data in React.
- How to handle user input and search functionality.

## ✨ Features

- Search weather by city name.
- Display weather information in a card.
- Show temperature and weather conditions.
- Display humidity, wind speed, and other weather details.
- Simple and user-friendly interface.

## 🚀 How to Use

1. Open the Weather App.
2. Enter your city name in the search bar.
3. Click the **Search** button.
4. The app fetches weather data for the entered city.
5. All available weather information is displayed in a weather card.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Weather API
